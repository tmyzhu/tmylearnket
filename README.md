# 英语记单词 · 新加坡绘本风格 + KET 备考方向

适合广州小学三年级学生的英语互动学习网页，包含：
- 新加坡小学绘本风格简易模拟内容（自创，避免版权问题）
- 记单词互动卡片（含记忆提示）
- Anki 标准格式卡片（制表符分隔，可直接导入）
- KET 备考方向对应表

## 绘本内容说明
本页面绘本主题参考新加坡小学英语教学常见方向（动物、学校、家庭、自然），内容为自创简易模拟版本。如需真实绘本，请通过正规渠道购买授权教材。

## 使用方式
1. 打开 `index.html` 在浏览器中练习
2. 复制 `.txt` 内容导入 Anki（文件 → 导入 → 选择制表符分隔）
3. 结合绘本故事朗读，建立词汇与语境关联
